# mtf-hub-for-trans
>本项目为共建项目，项目目前处于立项阶段。

## 项目简介
本项目计划建造属于mtf们的小仓库，欢迎你的加入为我们添砖加瓦，这对我们非常重要。
项目目前处于立项阶段，我们计划搭建 mtfhub 网站；为避开 mtf.wiki 的生态位，我们尚未确定本站最终目标。
未来可能转型为mtf群体only的社交平台。

## ⚠️ 重要隐私与安全声明
1. 本项目**严格保护隐私**，**不收集、公示任何人精确地理位置、联系方式、个人身份信息**
2. 所有贡献完全自愿；任何提交内容不能包含他人个人隐私信息
3. 禁止上传任何会导致个人被溯源的资料以及违反您所在地区法律法规的资料
4. 本项目不承担用户个人信息泄露带来的相关风险
